Реализована отправка рассылки через интерфейс.

Реализована отправка рассылки через командную строку (кастомной командой). 

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Выполните миграции:
   ```bash
   python manage.py migrate
   ```
3. Создайте суперпользователя (по желанию):
   ```bash
   python manage.py createsuperuser
   ```
4. Поднимите роли и разрешения:
   ```bash
   python manage.py setup_roles
   ```
5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

## Настройка email

править `config/settings.py`
- `EMAIL_USE_TLS` 
- `EMAIL_USE_SSL`.

  
Переменные окружения (файл `.env`)
Минимально необходимые переменные:
- `EMAIL_BACKEND` (обычно `django.core.mail.backends.smtp.EmailBackend`)
- `EMAIL_HOST`, `EMAIL_PORT`
- `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`

## Основные возможности

- Регистрация, подтверждение email, вход/выход, восстановление пароля.
- Управление получателями, сообщениями и рассылками (CRUD) через веб-интерфейс.
- Просмотр истории попыток отправки с результатами.
- Ручной запуск рассылки из интерфейса и через консольную команду.
- Дашборд со статистикой и кэшированием.
- Разграничение прав: пользователи работают только со своими данными, менеджеры — просматривают всех и могут отключать рассылки.

## Команды
```bash
python manage.py setup_roles
```
создание группы «Менеджеры» и назначение прав.


```bash
 python manage.py send_mailing <id>
```
разовая отправка рассылки с указанным идентификатором.
